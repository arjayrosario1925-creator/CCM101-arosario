## Linux Commands Used

* `pwd` – Used to identify the directory currently being accessed.
* `ls` – Used to view the contents of a directory.
* `cd` – Used to move from one directory to another.
* `mkdir` – Used to create folders needed for the laboratory.
* `touch` – Used to create the required Markdown files.
* `cat` – Used to display the contents of a text file.
* `nano` – Used to modify and add content to Markdown files.
* `ls -R` – Used to view the complete folder structure and its contents.
