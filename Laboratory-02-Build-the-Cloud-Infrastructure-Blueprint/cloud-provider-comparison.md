# Major Cloud Provider Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform (GCP) |
| :--- | :--- | :--- | :--- |
| *Compute* | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| *Storage* | Amazon S3 / EBS | Azure Blob / Disk Storage | Cloud Storage / Persistent Disk |
| *Networking* | Amazon VPC | Azure Virtual Network (VNet) | VPC Network |
| *Identity & Access Management (IAM)* | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |

---

### Analysis & Guide Questions

1. *Which cloud provider offers the broadest range of services? Explain your answer.*  
   Amazon Web Services (AWS) offers the broadest range of services, featuring over 200 fully featured offerings across various technical domains. Having launched first in 2006, AWS has built the largest third-party ecosystem and the most mature set of specialized cloud tools in the market.

2. *Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?*  
   Microsoft Azure is the recommended platform for Microsoft-centric organizations due to its native, seamless integration with tools like Active Directory, Windows Server, and Microsoft 365. Additionally, programs like Azure Hybrid Benefit allow enterprises to reuse existing Windows Server and SQL Server licenses to significantly reduce costs.

3. *Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?*  
   Google Cloud Platform (GCP) is widely recognized for its industry-leading capabilities in AI, Machine Learning, and big data analytics. Because Google originally created Kubernetes, GCP offers exceptional, highly optimized container management through Google Kubernetes Engine (GKE).

4. *What similarities did you observe among the three cloud providers?*  
   All three providers offer identical core infrastructure primitives including virtualized compute instances, scalable object storage, private virtual networks, and granular identity governance. They also utilize similar utility-based pricing structures (pay-as-you-go) and deliver high availability across global regions and availability zones.
