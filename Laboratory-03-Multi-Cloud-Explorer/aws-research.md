# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing service that offers many tools and resources for computing, storage, networking, databases, security, and other IT requirements.

## Global Infrastructure

AWS has a worldwide infrastructure made up of Regions and Availability Zones. These locations help businesses run their applications closer to their users while improving system availability and reliability.

## Cloud Management Console

The AWS Management Console is a web-based platform where users can create, set up, monitor, and manage their AWS services and resources.

## Four Core Services

### 1. Amazon EC2

Amazon EC2 allows users to create and use virtual servers for running applications and other workloads.

### 2. Amazon S3

Amazon S3 is an object storage service used to store files, data, backups, and other types of digital objects.

### 3. Amazon VPC

Amazon VPC allows users to create a private virtual network for their AWS resources and applications.

### 4. AWS IAM

AWS IAM is used to control access to AWS resources by managing users, roles, permissions, and access policies.

## Three Advantages

* Provides many different cloud services
* Has a worldwide cloud infrastructure
* Offers resources that can easily scale based on demand

## Typical Enterprise Use Cases

Businesses can use AWS to host websites and applications, manage databases, store data, create backups, perform data analytics, and build large-scale cloud infrastructure.
