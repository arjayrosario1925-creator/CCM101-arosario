# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that offers various services for computing, storage, networking, databases, security, artificial intelligence, and other business needs.

## Global Infrastructure

Azure has a worldwide infrastructure consisting of different regions and availability options. These allow organizations to run their services in different geographic locations.

## Cloud Management Console

The Azure portal is a web-based platform that allows users to create, set up, monitor, and manage Azure resources and services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computers that can be used to run applications and different workloads.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service used for storing files, documents, backups, and other unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network provides networking features that allow Azure resources to communicate securely.

### 4. Microsoft Entra ID

Microsoft Entra ID is an identity and access management service used to manage users, applications, and their access to resources.

## Three Advantages

* Works well with Microsoft products
* Offers services designed for businesses and enterprises
* Has a worldwide cloud infrastructure

## Typical Enterprise Use Cases

Organizations can use Azure for enterprise applications, Windows-based workloads, databases, identity management, Microsoft 365 environments, artificial intelligence, and hybrid cloud solutions.
