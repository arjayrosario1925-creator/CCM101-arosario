## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is known for having a wide selection of cloud services. These include computing, storage, databases, networking, security, analytics, and many other cloud solutions.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure is designed to work closely with Microsoft technologies. It integrates with products and services such as Windows Server, Microsoft 365, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is recognized for its artificial intelligence and machine learning services, as well as its support for Kubernetes. Kubernetes was originally developed at Google and is commonly used to manage containerized applications.

### 4. Which cloud platform would you personally choose and why?

I would choose Microsoft Azure because it offers a wide range of services and works well with Microsoft technologies. I also think it is useful for organizations that already depend on Windows and other Microsoft products.
