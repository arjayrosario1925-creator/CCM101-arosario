# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform that offers services for computing, storage, networking, databases, artificial intelligence, machine learning, and application development.

## Global Infrastructure

Google Cloud has a global infrastructure that allows organizations to deploy applications and services in different regions around the world.

## Cloud Management Console

The Google Cloud Console is a web-based interface where users can create, configure, monitor, and manage their Google Cloud resources.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that can be used to run applications and different workloads.

### 2. Cloud Storage

Cloud Storage is an object storage service used to store files, application data, backups, and other types of information.

### 3. Virtual Private Cloud

Google Cloud VPC provides networking services that allow cloud resources to communicate with each other.

### 4. Cloud IAM

Cloud IAM manages users, permissions, and access to Google Cloud resources.

## Three Advantages

* Provides strong artificial intelligence and machine learning services
* Offers strong support for Kubernetes and container-based applications
* Has a global cloud infrastructure

## Typical Enterprise Use Cases

Google Cloud can be used for web applications, data analytics, artificial intelligence, machine learning, containerized applications, and processing large amounts of data.
