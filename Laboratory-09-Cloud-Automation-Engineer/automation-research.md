# Automation Research

## 1. Bash Script

A Bash script is a file that contains a series of Linux commands that can be executed together. It helps users automate tasks instead of typing each command one by one. The first line, `#!/bin/bash`, is called the shebang. It tells the system that Bash should be used to interpret and run the script.

## 2. Variables

Variables are used to store values that a script can reuse when performing different operations. These values may include folder names, file locations, or timestamps. For example, the variable `$BACKUP_DIR` can represent the directory where backup files will be saved. Using variables makes a script easier to understand, maintain, and modify when changes are needed.

## 3. Cron Job

A Cron job is a Linux feature that allows commands or scripts to run automatically according to a specified schedule. Users can configure it to execute tasks at certain times, dates, or recurring intervals. In cloud computing, Cron is useful for automating regular activities such as creating backups, cleaning temporary files, and performing routine maintenance. It helps save time and reduces the need for manual work.

## Conclusion

Learning about Bash scripts, variables, and Cron jobs helped me understand the basic concepts of Linux automation. Bash scripts organize commands into a reusable process, variables make scripts more flexible, and Cron allows tasks to run on a schedule. Together, these tools can make cloud server management more efficient and help ensure that important routine operations are performed consistently.
