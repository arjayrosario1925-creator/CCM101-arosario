# Reflection

Completing Laboratory 09 gave me a better understanding of how automation works in cloud computing. I learned that Linux commands can be combined into a Bash script to perform tasks more easily. Instead of creating backups manually every time, I was able to write a script that compresses files and saves them in a backup directory. This showed me how automation can save time and make server management more convenient.

I also learned that automated processes need proper testing. Even a small error in a script, such as using the wrong directory or command, can prevent a backup from working correctly. If the system is not checked regularly, important files might not be backed up as expected. Because of this, I realized that it is important to verify the output of a script and make sure the backup files are created successfully.

Another thing I learned was the difference between Bash scripting and Docker Compose. Bash is useful for executing a sequence of commands to complete tasks such as file management and backups. Docker Compose is mainly used to configure and manage applications that run through containers. Although they have different purposes, both tools help simplify technical tasks through automation.

As I reviewed my previous laboratory activities, I noticed that I have gained more knowledge about managing Linux servers and working with cloud technologies. Each mission introduced different skills, from understanding basic server commands to deploying applications, improving security, and automating routine operations.

Among the activities I completed, I found this mission interesting because I could see the result of the script I created. Learning how Cron schedules tasks also helped me understand how servers can perform regular operations without constant manual supervision.

Overall, this activity taught me that automation is an important part of cloud computing. However, creating automated tasks is not enough; they must also be tested, monitored, and maintained to ensure that they work properly and protect important data.
